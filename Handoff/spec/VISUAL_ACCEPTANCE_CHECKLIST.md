# Visual Acceptance Checklist

Claude must compare the simulator screenshot against `assets/reference/04-creator-dashboard-system-mockup.png` before moving on.

## Score: 10 points total

### Layout fidelity — 2 points
- Same module order and relative proportions
- Same technical-grid feel
- No module added, removed, or moved without approval

### Typography fidelity — 2 points
- Strong editorial size contrast
- Labels small and technical
- Numeric values dominant where intended
- Quote retains emotional weight

### Color fidelity — 1 point
- Dark green dominates
- Orange is a signal, not decoration
- No blue, purple, gradients, or random accent colors

### Cutting-mat detail — 2 points
- Major/minor grid visible but restrained
- Ruler/tick/crosshair/registration details intentional
- Does not look like ordinary graph paper

### Anti-AI-slop discipline — 2 points
- No floating rounded-card dashboard
- No glassmorphism, gradients, glow, giant SF Symbols, progress rings, SaaS styling

### Quote hierarchy — 1 point
- `WHO ARE YOU GOING TO BE TODAY?` remains visually important
- `TODAY?` may use signal orange in hero/calm state

## Minimum acceptable score: 9/10

If below 9/10, revise before presenting the build.

## Required first-pass review

Check:
- proportions
- spacing
- alignment
- font sizing
- weight
- tracking
- line height
- divider weights
- grid density
- grid opacity
- orange usage
- icon scale
- corner treatment
- quote prominence

Do not proceed to live data until Bradley approves the static visual build.
